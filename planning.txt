Routes

User Authentication:
/signup: POST -Create a new user account.
/login: POST- log in to an existing account.

voting:
/candidates: GET = Get the list of Candidates.
/vote/:candidatesId: POST - Vote for a specific candidates

Vote COunts:
/vote/counts: GET - Get the list of Candidates sorted by their vote counts.

User Profile:
/profile: GET -Get the user's profile information.
/profile/password: PUT - CHanges the user's password.

Admin Candidates management:
/candidates: POST -Create a new candidates
/candidates/:candidates: PUT -Updates on existing candidates
/candidates/:candidates: DELETE -Delete a candidate from the list.
